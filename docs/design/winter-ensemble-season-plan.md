# 第五赛季 · 冬日群像规划

状态：已实现到仓库配置与渲染器，尚未部署；隔离验收与实际预览见文末。

日期：2026-11-17。

视觉规范见[冬日群像主题设计](winter-ensemble-render-kit.md)。本文件负责赛季内容、
卡池、奖励、排期和生命周期；页面排版遵循主题设计，不重复制定视觉规则。

## 1. 本季定位

第五赛季回到 BanG Dream! 群像，以冬装角色和统一冬日主题组成一整季内容。
赛季持续至元旦前，给玩家比常规 28 天赛季更充足的参与和收集时间。

推荐赛季名称为「冬日合奏」，主题装扮同名。名称仅用于赛季、卡池和物品辨识，
不作为所有页面的页眉、口号或水印。此前的「把冬夜唱亮」不进入常规界面文案。

本季交付为一套固定主题、一期完整限定卡池和一次赛季结算。
不拆上下半池，不新增活动货币，不增加日期驱动的换肤、阶段任务或限时双倍 Pt。

## 3. 推荐阵容

以香澄与灯作为双六星，分别承担热闹、主动和安静、陪伴的角色气质。
其余角色分布在不同乐队，强调相遇与同行。群像不要求每支乐队平均分配星级，
也不宣称覆盖全部乐队。

以下名单是制作候选，不代表已经找到对应卡图或已经获得用户对阵容的确认。

| 星级 | 候选角色 | 画面方向 |
| --- | --- | --- |
| 六星 | 户山香澄 | 围巾、冬装，招呼同伴或准备出发；温暖且有动感 |
| 六星 | 高松灯 | 冬装、安静的街角或热饮；与香澄形成自然互补 |
| 五星 | 丸山彩 | 冬日外出、耳罩或围巾，明亮轻快 |
| 五星 | 弦卷心 | 冬日街区、礼物或招呼同伴，活泼但不依赖圣诞符号 |
| 五星 | 仓田真白 | 清冷冬装，与浅雪和纸白色调协调 |
| 五星 | 朝日六花 | 日常冬装与乐器元素，连接音乐场景 |
| 四星 | 美竹兰、今井莉莎 | 日常冬装，补足街区相遇的群像关系 |
| 四星 | 市谷有咲、山吹沙绫 | 围巾、外套与日常气氛，不重复第一季已有立绘物品 |
| 四星 | 千早爱音、仲町阿拉蕾 | 冬季外出形象；阿拉蕾需优先核实可用素材 |

目标为 12 张立绘：2 张六星、4 张五星、6 张四星。
立绘名称采用「角色名＋原卡名」，优先使用素材记录中的简体中文原卡名，
缺失时回退日文原名。不得统一追加「冬日」来替换原卡名。
六星身份来自本项目的赛季配置，不能把它写成原作卡牌的官方星级。

### 素材筛选与替换规则

优先选择可追溯来源的冬装透明立绘或具备清楚分层的角色素材。
Bestdori 卡号、具体版本、文件路径和哈希在选材后记录，不在规划中猜测。

不把上一轮 AI 印象图中的人物裁切为正式立绘。完整场景卡面如果无法干净提取
人物，不能冒充透明立绘交付；可以作为卡池海报的候选背景。

候选角色没有合适冬装时，优先替换同档候选，并保持档位人数、出率和同档等权。
不强行给现成夏装加雪花来凑冬装。双六星若需要替换，应在卡池公示前完成，
并更新阵容、立绘、卡池展示与奖励元数据。

阿拉蕾作为优先排查项；无合适素材时四星席位建议由已有冬装素材的其他邦邦角色
替换。素材确认前不将任何候选列为已完成资产。

## 4. 卡池与获得规则

沿用第四季的实际卡池档位与费用。一次开放整期内容，开季即可抽取全部角色。

| 项目 | 推荐规则 |
| --- | --- |
| 单抽 / 十连 | 120 / 1200 星星贴纸 |
| 六星基础合计出率 | 1%；两位同档等权，各 0.5% |
| 五星基础合计出率 | 20%；四位同档等权，各 5% |
| 四星基础合计出率 | 79%；六位同档等权，各约 13.17% |
| 三星 | 本期不设 |
| 软保底 / 硬保底 | 第 70 抽开始软保底，第 90 抽必出六星，沿用现有算法 |
| 保底继承 | 沿用现有跨赛季保底计数，不为本季重置 |
| 卡池构成 | 本期选定冬装立绘，不混入会动态变化的普通池 |

以上为软保底前的基础概率。进入软保底后六星概率上升，其他档位按现有算法调整。
第 90 抽保证的是六星档位，不保证指定角色，也不保证集齐双六星。
十连沿用现有抽取流程，不另承诺未实现的五星保底、自选或定轨。

奖励组合沿用现有 `grant_featured_character_reward`：

1. 首次获得本季任意六星：该角色立绘、共享角色框、冬日主题。
2. 获得另一位六星：该角色立绘，不重复发放共享框和主题。
3. 重复立绘按现有补偿规则发放盆栽：六星 60、五星 50、四星 40。
4. 已从其他渠道拥有主题时，依现有物品服务处理重复；上线前核对展示结果。

卡池立绘为本期限定内容。赛季结束后不自动进入普通池或流星堂；未来若复刻，
单独制定安排，不承诺永久绝版，也不承诺具体复刻日期。

## 5. 排名奖励与参与边界

本期基线采用第四季 `seasons.json` 已配置的四档奖励，主题发至前十。
不将较早通用设计中的称号设想写成已经存在的自动发放行为。

| 最终排名 | 星星贴纸 | 头像框 | 主题 |

| 第 1 名 | 2400 | 冠军框 | 冬日主题 |
| 第 2–3 名 | 1200 | 前三框 | 冬日主题 |
| 第 4–10 名 | 600 | 前十框 | 冬日主题 |

每人只获得符合名次的最高一档排名奖励。框的视觉层级依名次区分，角色抽卡框
与排名框分别设计，排名框不能由抽卡或商店获得。

本期基线不新增称号和参与礼包，不配置 `participation_reward`。
参与数据继续由现有机制记录，但参与记录本身不等于有一份未公示的奖励。
如后续确需加入参与奖励，须同步修改本文件、物品定义、赛季配置和公示内容。

赛季较长带来更多日常参与机会，保持现有每日奖励、Pt 来源、抽卡费用与四档结算
数量，不按天数机械放大。流星堂季内加抽继续每次 400 盆栽、每人每季最多 5 次，
抽取即时执行并计入现有保底，不因为跨入十二月而刷新额度。

排名依据现有赛季 Pt 口径和同分排序规则，不新增累计消费榜、抽卡榜或阶段排名。
本季 Pt 不由旧季余额结转；永久资产、星星贴纸与盆栽沿用现有作用域规则。

## 8. 开季与结束行为

### 开季

- 以真实配置验证第四季结束、本季开启，任一请求只归属一个有效赛季。
- 初始 Pt 按现有机制处理，不覆盖玩家永久资产，也不重置抽卡保底。
- 核对本季卡池和流星堂加抽均指向本季，角色附赠物品指向同一共享框和主题。
- 对已开始但跨越边界的游戏或资金占用，沿用现有生命周期与作用域处理，
  不把旧季结束后的退款或结算误计入本季。

### 元旦边界与结算

- `2027-01-01 00:00:00+08:00` 起，本季不再接受新的计分和卡池抽取。
- 按现有流程处理未结束对局、资金占用与最终积分，生成并保留最终排名。
- 按最高排名档生成奖励记录，发送奖励邮件；失败重试须保持幂等，不重复发奖。
- 卡池关闭不清除已有立绘、主题、头像框、抽卡历史或跨季保底计数。
- 冬日主题继续可装备和渲染，不读取日期换肤，不出现过期倒计时或固定年份水印。
- 无下一赛季时进入休赛期；临时 Pt 不作为本季后续排名，也不结转为下季积分。

赛季、卡池、资产所有权分别处理：结束的是本季竞争和获得窗口，已经获得的资产
继续保留。主题不在季末自动加入盆栽商店，排名框也不转售。
