# Bundled font sources

Both fonts in this directory are distributed under the SIL Open Font License
1.1. Their license texts are stored beside the font files.

- Source Han Serif SC SemiBold: <https://github.com/adobe-fonts/source-han-serif>
  (copied from the repository's existing unmodified Source Han Serif bundle;
  the duplicate keeps this kit independent of another theme's package).
- Cormorant SC SemiBold: <https://github.com/CatharsisFonts/Cormorant>
  at commit `9719e26aa8e26d7a30e736667427b9e05b5db059`.

The files are used only for typography. All ornaments in this kit are drawn
programmatically and contain no official Roselia logo or artwork.
